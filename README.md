# PG Management System (Frontend Only)

The **PG Management System** is a frontend web application built using **HTML, CSS, and JavaScript**.  
It is designed to provide a simple digital interface for managing Paying Guest (PG) accommodations.  
This project focuses only on the **UI/UX (no backend or database integration)**.

---

## 🚀 Features
- 🔑 **Login Page (UI only)** – Separate mock login for owners and residents.  
- 🍴 **Food Menu Display** – View daily/weekly food menus.  
- 🧹 **Cleaning Schedules** – Check maintenance and cleaning updates.  
- 🏖️ **Vacation Requests** – Residents can submit vacation requests (UI demo).  
- 📝 **Issue Reporting** – Simple form for raising complaints or issues.  

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the web pages  
- **CSS3** – Styling and layout (responsive design)  
- **JavaScript (Vanilla JS)** – Form handling, interactivity, and UI logic
